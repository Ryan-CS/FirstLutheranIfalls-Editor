# Fonts

Fonts are public website content and belong in the Website repository, not the Editor repository.

- Website source path: `assets/fonts/` in `FirstLutheranIfalls-Website`
- Website CSS path: `assets/fonts.css` in `FirstLutheranIfalls-Website`

Font maintenance is a normal Website-repository change: edit the files directly on the Website repository (or via the editor's Save Draft / Publish flow if the font files are exposed as editable content), same as any other asset. There is no separate font tooling in this repository.

> The `$WEBSITE_ROOT`-relative paths this document previously referenced described the retired local Node server (`server/`), which is no longer deployed. See `docs/WORKER-MIGRATION-TEST.md` for the current architecture.
